# delta2-battery

[English](README.md) | **繁體中文**

一個小巧、深色、扁平的 Windows 系統匣小工具，用來顯示 **ASUS ROG Delta II** 耳機透過 **2.4G 接收器** 連線時的電量，不需要開 Armoury Crate。

> **非官方專案。** 這是社群個人製作的獨立工具，與華碩（ASUSTeK Computer Inc.）無關，也未獲其授權或背書。「ASUS」「ROG」為華碩的商標，這裡僅用來說明本工具適用的硬體。

## 功能

- 直接從 2.4G 接收器經 USB HID 讀取電量，並自動更新（每 30 秒）。
- 小巧、扁平的深色視窗，可拖曳；關閉後縮到系統匣。
- 系統匣圖示直接顯示數字：綠色、琥珀色（≤ 30%）、紅色（≤ 15%）。
- 充電時，視窗的數字旁會出現閃電，系統匣的數字則會慢慢漸亮漸暗（呼吸效果）。
- 電量 20% 以下跳出低電量通知（電量回到 30% 或以上才會再次提醒）。
- 可選擇開機自動啟動，並以最小化狀態只留在系統匣。
- 只能開一個實例，不需安裝、沒有背景服務。

## 下載

到 [Releases](../../releases) 頁面下載最新版：

| 檔案 | 說明 |
| --- | --- |
| `DeltaBattery.exe` | 單一檔案版，最方便，但比較容易被防毒軟體誤判（見下方）。 |
| `DeltaBattery-folder.zip` | 資料夾版。解壓縮後執行 `DeltaBattery.exe`，整個資料夾要一起保留。 |

Windows 64 位元，不需要安裝 Python。目前只在作者的電腦上建置與測試。

## 使用方式

1. 插上耳機的 2.4G 接收器，並開啟耳機。
2. 啟動程式，幾秒內就會顯示電量。
3. 在系統匣圖示按右鍵，可選擇「顯示視窗」「立即更新」「開機自動啟動」「結束」。

視窗上的狀態文字：

| 狀態 | 意思 |
| --- | --- |
| 2.4G 已連線 | 找到接收器，耳機也有回應。 |
| 耳機未連線 | 找到接收器，但耳機沒開機或距離太遠。 |
| 未偵測到接收器 | 沒有插上支援的接收器。 |

如果程式讀不到接收器，而你有開著 Armoury Crate，請先把它關掉，兩者可能會搶用同一個裝置。

## 支援的硬體

| 項目 | 內容 |
| --- | --- |
| 耳機 | ASUS ROG Delta II（2.4G 模式） |
| 接收器 USB ID | `VID 0x0B05` / `PID 0x1AFA` |

目前只在一台（黑色版）上開發與測試。**其他版本（例如白色版）、地區版或韌體版本，PID 或資料內容可能不同。** 如果你的耳機無法使用，歡迎開一個「Hardware report」issue，並附上 [`tools/`](tools/) 裡腳本的輸出，這是新增支援最快的方式。

## 從原始碼執行

```bat
pip install hidapi PySide6
python delta2_battery.py
```

需要 Windows 與 Python 3.9 以上。加上 `--minimized` 可以只啟動到系統匣。

## 自行打包 exe

```bat
build.bat            :: 資料夾版 -> dist\DeltaBattery\DeltaBattery.exe
build_onefile.bat    :: 單一檔案 -> dist\DeltaBattery.exe
```

推送像 `v0.1.0` 這樣的 tag，GitHub Actions 也會自動打包兩種版本並附加到 Release。

## 運作原理

接收器提供一個廠商自訂的 HID 介面（usage page `0xFF00`）。程式送出 64 bytes 的查詢封包並讀取 64 bytes 的回應；耳機在連線或插拔充電線時也會主動推送狀態。詳細的格式與找出它們的過程，請見 [`docs/PROTOCOL.md`](docs/PROTOCOL.md)。

程式只會**讀取狀態**，不會寫入任何設定到耳機，不碰韌體，也沒有使用任何華碩的程式碼。

## 防毒軟體警告

用 PyInstaller 打包的執行檔，有時會被 Microsoft Defender 等防毒軟體**誤判**，單一檔案版尤其容易。本程式做的所有事都在這個 repo 的原始碼裡。如果被擋下，你可以：

- 改用資料夾版，不要用單一檔案版；
- 直接用 Python 從原始碼執行（見上方）；
- 或用 `build.bat` 自己打包。

## 已知限制

- 僅支援 Windows。
- 只在一組耳機與接收器上測試過；充電旗標的值（`1` = 充電中）也只在該組上驗證。如果顯示相反，可以改 `delta2_core.py` 裡的 `CHARGING_VALUE`。
- 不支援藍牙與有線模式：本程式只和 2.4G 接收器溝通。
- 這是從觀察 USB 資料逆向得來的，韌體更新後行為可能改變。
